1週間の学習・制作報告

今回の報告

この1週間は、プロフィールサイトを公開用として見やすく整えることを中心に取り組みました。 初めて見る人にも内容が伝わるように、文章、導線、学習成果、共有方法を改善しました。

今回の対象

今回の報告対象は、プロフィールサイトです。他の制作アプリとは分けて、 自己紹介ページとして改善した内容をまとめています。

1分で説明する流れ
  1. 1何を見やすくしたか
  2. 2何ができるようになったか
  3. 3次に整えること
最初に伝えたいこと

介護経験を土台に、Web制作を学んでいることが伝わるプロフィールサイトへ改善しました。 公開ページとして、PCとスマートフォンの両方で見やすい形に整えています。

1. この1週間でやったこと

見る順番の整理

プロフィール、学習成果、報告資料の順番で見られる案内を追加しました。

学習成果の見せ方

作ったもの、操作、工夫した点を作品紹介として分かりやすく整理しました。

共有しやすさ

報告ページ、PDF、画像、QRコードを使って共有しやすい形にしました。

2. 具体的に改善したこと

初めて見る人への案内

  • 見る順番の案内を追加しました。
  • 「まずここだけ」の要約を残し、短時間でも内容が伝わるようにしました。
  • プロフィールから学習成果へ移動しやすくしました。

学習成果の整理

  • 制作物として見てほしいポイントを追加しました。
  • 使った技術、工夫した点、公開方法を整理しました。
  • できるようになったことをカード形式で表示しました。

スマートフォン対応

  • 文字やボタンを見やすく調整しました。
  • 下部メニューから移動しやすくしました。
  • QRコードの説明を追加しました。

共有しやすくした

  • 報告ページをおすすめとして分かりやすく表示しました。
  • PDFと画像でも共有できる形にしました。
  • 個人の連絡先やSNSは載せない形にしました。

3. できるようになったこと

HTML

見出し、カード、リンク、QRコード説明などを使って情報を整理しました。

CSS

余白、文字の見やすさ、カード表示、スマートフォン表示を調整しました。

JavaScript

タブ切り替え、画像切り替え、URLコピーなどの操作を使いやすくしました。

4. PDCA

計画

プロフィールを、初めて見る人にも流れが分かる形にする。

実行

見る順番、作品紹介、共有資料、QRコード説明、最後のメッセージを改善した。

確認

ローカル表示で確認し、GitHubの公開ページにも反映した。

改善

今後はスマートフォンでの見え方を確認し、文章量やボタン位置を整える。

5. 次に取り組むこと

  1. スマートフォンで実際に見て、文字量やボタンの押しやすさを確認する。
  2. 学習成果が増えたら、短く分かりやすく追記する。
  3. 他の制作アプリは、プロフィールサイトとは分けて報告を整理する。
  4. プロフィール公開ページの最終確認を続ける。
